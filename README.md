# Intelligent AI Voice Agent

An AI-powered multilingual voice agent supporting English and Malayalam.

## Planned Architecture

Speech Input
    ↓
ASR
    ↓
Malayalam → English Translation
    ↓
LLM / AI Agent
    ↓
Tool Calling / RAG
    ↓
Response Generation
    ↓
English → Malayalam Translation
    ↓
Text-to-Speech
    ↓
Voice Output
